# Welcome to the Nanodjango Static Site

This is a simple static site built with [nanodjango](https://nanodjango.dev/), [django-nanopages](https://github.com/radiac/django-nanopages), and [django-distill](https://github.com/meeb/django-distill).

It demonstrates generating static HTML from Markdown pages and deploying via GitHub Pages using a workflow.

## Features

- Markdown content in the `pages/` directory
- Django-powered rendering with optional dynamic models
- Static generation for easy deployment
- Hot reload during development with django-browser-reload

Check out the [About](about/) page or the original [blog post](https://nanodjango.dev/blog/2026-10-static-site-builder/).
