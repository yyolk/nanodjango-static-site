# Welcome to the blog

This is a dated post stored as a Markdown file under `pages/blog/`.

No model, no SQLite, no admin. The date is in the filename and frontmatter.

## Why this works

- Nanopages serves any `.md` file under the registered path
- The filename becomes the URL slug
- Frontmatter can hold title, date, tags, etc.
- Distill freezes it to static HTML

Add more posts the same way.
